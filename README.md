# Document Data Extractor

A web application with a React frontend and Flask backend to extract data from documents.

## Getting Started

### Prerequisites
- Node.js (for frontend)
- Python 3.x (for backend)
- Flask, OpenCV, Pytesseract, PyMuPDF, and SpaCy (for Python backend)

### Installation

1. Clone the repository to your local machine.

2. Setup the frontend:
   ```bash
   cd frontend
   npm install
   npm start
